# Презентация SLAY AWARD

Админ-панель → Презентация. Выберите номинацию, режим участников и место.

- «Неизвестный участник»: репетиция с чёрным силуэтом Матвея.
- «По голосованию»: имена и фотографии автоматически берутся из загруженных итогов при открытии каждой сцены. «Обновить итоги» загружает актуальный снимок. Уже открытая сцена не меняется посреди выступления.
- Стрелки ← → переключают места; Escape или «Закрыть» завершают показ. «Повторить» запускает появление заново. Движение продолжается до закрытия.

Включено 35 сцен: места 3 → 2 → 1 для 11 номинаций, только 1 для «Инцел года» и «2008 этого года». «Ситуация года», «Тикток года» и проигравшие исключены.

Используется существующий getNominationResults: учитываются только разрешённые серверным адаптером голоса. При равенстве баллов порядок остаётся таким же, как в «Итогах» (алфавит), и показывается пометка. При отсутствии результата показывается силуэт. Имена сопоставляются точно с каталогом NOMINATIONS. Для записей без photo, включая анекдоты и пары, выводится название с силуэтом; достаточно добавить photo в объект участника, чтобы сцена использовала его автоматически.

Фоны — выбранный вариант 2. Внешний вид: presentation.css. Управление: presentation.js. Разрешённые места и сопоставление результатов: presentation-model.js. Реализован prefers-reduced-motion. При закрытии DOM сцены удаляется, бесконечные анимации прекращаются.
