# Живая церемония SLAY AWARD

Админ-панель → Презентация → выберите номинацию → **Запустить церемонию**.

Для всех 16 номинаций работает одна последовательность:

1. Название номинации и её озвучка.
2. По окончании речи — непризовые участники одной линией: от последнего места к четвёртому. Добавленная к опубликованным подводкам трёхсекундная монтажная тишина пропускается по времени самого аудио. Группа входит вместе с первой репликой; затем озвучиваемая карточка подсвечивается. В длинном списке линия плавно подводит следующую карточку в видимую область до произнесения имени.
3. Пьедестал: третье → второе → первое место. Каждая карточка начинает появление по фактическому событию `playing` соответствующей записи имени. Следующая запись начинается после окончания предыдущей; фиксированного таймера между местами нет. При буферизации появление приостанавливается, а после восстановления звука продолжается без повторного раскрытия. Второе место слева, первое по центру, третье справа.
4. Имена, фотографии, места и аудио берутся из одного снимка итогов. Пока звук загружается или браузер ждёт разрешения на воспроизведение, следующее призовое место скрыто. Если запись отсутствует или не загрузилась, карточка показывается без звука с паузой 2,4 секунды. Все появления остаются плавными.

Каждый запуск и переход к результатам запрашивают свежие данные через существующий `renderAdmin`. Отображаемый порядок берётся из `getNominationResults`, который учитывает только разрешённые серверным адаптером голоса. Для разрешения равенства баллов используется тот же русский алфавитный порядок. Каталог номинантов не меняется.

Админский кеш также обновляется каждые 30 секунд, пока раздел открыт. Уже раскрывающиеся места сохраняют один снимок до конца показа, чтобы участники не перескакивали. **Повторить с новыми итогами** заново загружает данные. Новые итоги через месяц не требуют изменения анимации или пересборки видео.

Номинации с двумя участниками показывают только существующие места. Участники без голосов остаются в общей линии с пометкой «Пока без голосов» и не получают призовые места. Если голосов нет вообще, пьедестал не объявляет победителя.

В режиме **Репетиция с силуэтами** имена и фото скрыты. Кнопка **К участникам / К пьедесталу** позволяет пропустить текущий этап; Escape или **Закрыть** останавливают звук, таймеры и анимацию. **Включить озвучку** появляется, если браузер потребует отдельное разрешение на воспроизведение. Поддержан `prefers-reduced-motion`.

## Аудиофайлы

## «Тикток года»: видео перед объявлением

Перед названием каждого участника автоматически проигрывается его полный MP4 из каталога. Порядок тот же, что в актуальных итогах: непризовые места от последнего к четвёртому, затем 3 → 2 → 1. Файл сопоставляется по личности из снимка голосования, а не по фиксированному месту в списке.

Во время ролика голос ведущего не звучит. После события `ended` видеосцена плавно исчезает, затем звучит название и подсвечивается карточка или раскрывается соответствующее призовое место. Вертикальные видео показываются целиком без обрезки. Работают исходный звук, общий переключатель звука, встроенные управление и перемотка. Если браузер запрещает автозапуск, появляется кнопка **Воспроизвести видео**.

Во время просмотра **Пропустить ролик** завершает только текущее видео и продолжает его объявление. Закрытие, повторный запуск и выход из админки останавливают видео и отменяют продолжение прежнего показа. Недоступный ролик не блокирует церемонию. В репетиции с силуэтами видео скрыты вместе с личностями участников. Остальные номинации работают без видеовставок.

## Подключение озвучек

Пути берутся из `audio/slay-2026/manifest.json` при загрузке раздела; отсутствующие записи не заменяются случайными именами. Сейчас подводки «Пара года», «Качок года» и SLAY KING отсутствуют в пакете. Для этих номинаций название показывается 3,5 секунды, затем начинается раскрытие результатов. Если файл недоступен, показ продолжится без него. После добавления отсутствующих записей и обновления manifest.json озвучка подключится автоматически.

Проверяются смена победителя при новых голосах, стабильность прежнего снимка, полные списки всех 16 номинаций, два участника, пустые итоги, отсутствие выдуманных призовых мест для нулевых результатов, совпадение алфавитного порядка и выбор аудиозаписей по актуальной личности.
