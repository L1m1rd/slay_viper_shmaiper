# Тестирование администратора

Одобренные администраторы могут выбирать места в обычных номинациях даже до открытия основного этапа. Эти выборы хранятся в localStorage отдельно по ID администратора, в ключе slay-admin-test-v1:<id>. Они не отправляются в Supabase и не синхронизируются между браузерами. Настоящие итоги продолжают исключать профили с ролью admin.

В отборе и плей-офф кнопка «Тестировать голосование» включает отдельный режим. Закрытый отбор можно проверить, не открывая его для участников. Тестовая сетка плей-офф начинает с 1/8 финала; единственный тестовый бюллетень определяет победителей для проверки переходов через все четыре раунда. «Сбросить тест» очищает текущую симуляцию. «Выйти из теста» возвращает настоящий этап и результаты. Настоящее управление раундами доступно администратору после выхода из теста.

Тестовые чемпионы не передаются в результаты номинации и презентацию. Производственные таблицы, функции подсчёта, права доступа и статусы этапов этой реализацией не меняются.
